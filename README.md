# PV5 Wood Studio

PV5 카고 적재함을 이동형 사무실로 구성하는 단일 HTML 3D 시뮬레이터입니다.

## 실행

정적 서버에서 `index.html`을 열면 됩니다.

```bash
python3 -m http.server 8765
```

브라우저에서 `http://127.0.0.1:8765/`에 접속합니다.

## 포함된 배치

- 1안: 후면 데스크 + 횡방향 침상
- 2안: 우측 데스크 + 종방향 침상
- 3안: 후면 전폭 수납함 + 우측 데스크 + 격벽측 침상
- 163cm 착석 인체 표시
- 전면 캐빈, 운전석·조수석과 스티어링 휠
- 2·3안 우측 책상 1,200 × 700mm
- 27인치 모니터암과 노트북 스탠드
- 우유상자 8개와 상부 리프트 도어
- 휠하우스 사이 폭 1,330mm를 유지한 좌우 반원형 내부 휠하우스

Three.js `0.170.0`을 jsDelivr에서 불러옵니다.
